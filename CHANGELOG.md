# Changelog

All notable changes to KarateApp are documented in this file.

## [1.2.0] - Unreleased

- Added the native iOS rating prompt when leaving a seminar detail view.
- Added an "App bewerten" action for the Apple App Store and Google Play.
- Added required `APP_STORE_ID` and `GOOGLE_PLAY_APP_ID` build variables.
- Reused the configured Google Play application ID as the Android package name.

## [1.1.4] - 2026-08-02

- Added the published iOS App Store URL to the backend website and deployment configuration.
- Removed unused iOS camera, photo-library, and Face ID permission descriptions.
- Improved the German iOS location permission descriptions.

## [1.1.3] - 2026-08-01

- Declared German as the iOS development region and supported localization.

## [1.1.2] - 2026-08-01

- Added the backend support page with contact and issue-reporting information.
- Added the support page to the website footer.
- Fixed Apple bundle versioning to include the patch version.
- Added the missing WebView import to the seminar PDF view.

## [1.1.1] - 2026-07-26

- Fixed the Android package configuration.
- Updated the Android version code.

## [1.1.0] - 2026-07-26

- Added privacy and imprint pages to the backend website.
- Added the legal and privacy section to the app.
- Added source attribution throughout externally sourced content.
- Improved privacy-related backend behavior and access statistics.
- Improved Android compatibility, including 16 KB page-size support.
- Added App Store and Google Play release assets.

## [1.0.0] - 2026-05-14

- Initial KarateApp release.
- Added seminar discovery with list, map, distance, filtering, calendar export, and PDF support.
- Added DJKB news, gallery, and dojo browsing.
- Added the backend API, website, caching, geocoding, and deployment configuration.
- Added Android, iOS, macOS, Windows, and Linux build and packaging support.
