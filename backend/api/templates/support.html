Support für KarateApp

Hilfe bei Fragen, technischen Problemen und Verbesserungsvorschlägen

Kontakt

Schreibe eine E-Mail an karateapp@gmx.de. Die Support-Anfrage ist kostenlos.

Problem melden

Damit das Problem möglichst schnell nachvollzogen werden kann, gib bitte Folgendes an:

  • die verwendete Plattform, zum Beispiel iOS, Android, macOS, Windows oder Linux,
  • die Version der KarateApp,
  • eine kurze Beschreibung des Problems und der Schritte, die dazu geführt haben,
  • falls hilfreich, einen Screenshot ohne persönliche oder vertrauliche Daten.

Fehler und Verbesserungsvorschläge können alternativ öffentlich über GitHub Issues gemeldet werden.

Datenschutz

Informationen zur Verarbeitung von Daten stehen in der Datenschutzerklärung. Angaben zum Betreiber befinden sich im Impressum.
